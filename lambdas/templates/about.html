PRONOM is an online database that provides clear, reliable information about digital file formats.

What is PRONOM?

Archivists and others use PRONOM to understand the technical details behind files so they can keep important digital records accessible over time. A key part of PRONOM is its database of file format signatures. These are small patterns inside a file that help tools identify exactly what format it is. Knowing the precise format helps you plan how to maintain access and readability, especially as older formats become harder to open.

PRONOM holds the details of over 2,000 individual file formats including how to identify them. This information has been created through research by The National Archives (UK) and contributions by many archives and related organisations across the world.

PRONOM is widely used as part of digital preservation activities to help organisations understand the files they hold so that they can manage their readability over time.

PRONOM data can be used in tools such as DROID, which is a software application developed by The National Archives (UK). DROID scans files and uses PRONOM data to identify them, helping users identify, manage, understand and preserve their digital content.

PRONOM is freely available for anyone who needs reliable information about file formats.

Using PRONOM

PRONOM contains detailed information about file formats including

  • file format names and versions
  • file format details, background information and links to further resources
  • technical details used for file format identification.

You can search PRONOM in a few ways, including

  • by file format name, for example Microsoft Word
  • by PRONOM Unique Identifier (PUID) for example fmt/2000
  • by file extension, by preceding this with a dot, for example .doc.

Accessing PRONOM data

PRONOM data is openly available and can be accessed in different ways

  • Searching the website
  • Accessing the full dataset on GitHub as JSON files
  • Downloading XML files containing identification information, by appending .xml to a format page address, e.g. https://pronom.nationalarchives.gov.uk/fmt/1.xml
  • Downloading JSON files containing identification information, by appending .json to a format page address, e.g. https://pronom.nationalarchives.gov.uk/fmt/1.json
  • Downloading a JSON file containing the binary and container signature versions. This also includes links to the latest and all previous signature sets.
  • Downloading the latest binary signature at https://pronom.nationalarchives.gov.uk/binary-signature.xml
  • Downloading the latest container signature at https://pronom.nationalarchives.gov.uk/container-signature.xml
  • Downloading the full release notes https://pronom.nationalarchives.gov.uk/release-notes.xml

For more technical details, including documentation and source code, please visit the PRONOM GitHub repository.

Contributing to PRONOM

We actively encourage the submission of new information to improve PRONOM. If you have information on a file format that is not currently in the database, believe you could improve an entry, or have feedback, then please do get in touch.

Currently, to contribute to PRONOM, the easiest way is to submit an issue via our PRONOM Research GitHub repository, where a member of the team can pick it up easily. We can also be contacted via email at pronom@nationalarchives.gov.uk.

We are currently working on improving our contribution process and this guidance will be updated as new options become available.

The new PRONOM website

This new (beta) version of the PRONOM website launched in October 2026, replacing the old system which had been in use for over 20 years. You can still browse an archived version of the old PRONOM website on the UK Government Web Archive.

The new PRONOM is designed to

  • improve accessibility, usability and sustainability
  • support open and community-driven development
  • make it easier to access and reuse data
  • increase transparency by using open-source tools.

While the core PRONOM data remains consistent between the two systems, the new PRONOM changes how the system is delivered by

  • using modern, cloud-based technology
  • making data openly available via GitHub
  • supporting easier integration with external tools.

Feedback

The new PRONOM website is still in beta stage, and we want to make sure to get as much feedback as possible before taking it live and using it as our current website. If you have any suggestions for improvements, please fill out our feedback form.
